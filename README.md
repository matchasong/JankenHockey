# JankenHockey

じゃんけんの手を撃ち合うホッケーゲーム


## 概要

じゃんけんの手を撃ち合う、2 人対戦ゲームです。

- 画面下側の発射台からじゃんけんが発射されます
- 画面上側の相手のラインまで辿り着くと得点
- 1 分間で多く得点したほうが勝ち

自分のじゃんけんの手と、相手のじゃんけんの手がぶつかると、じゃんけんの勝ち負けに応じて手が消えます。
発射台を左右に動かして、相手の手に勝てそうな時はぶつけに行ったり、負けそうな時は避けたりして、戦略的に得点を狙いましょう。

### ゲームモード

- CPU 対戦モード
- オンライン対戦モード
